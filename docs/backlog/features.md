## F-16. Эксперимент по вплетению грамматических конструкций
- **Приоритет:** P3 — требует отдельного решения владельца перед реализацией.
- **Проблема/мотивация:** Встреча конструкции в естественном чтении полезна, но
  текущий строковый `termAppearsIn` не может подтвердить синтаксический шаблон,
  а принудительное вплетение рискует ухудшить текст.
- **Что сделать:** Спроектировать opt-in эксперимент: не более одной
  due-конструкции на статью, структурированное подтверждение из финального
  текста и независимый аудит естественности/CEFR-fit. Экспозиция не даёт
  SRS-кредит.
- **Критерии приёмки:** до кода утверждены дизайн и бюджет; контрольная группа
  не получает grammar target; неподтверждённый паттерн не считается встречей;
  качество статьи не ослабляется; стоимость учитывается отдельно.
- **Детали/ссылки:** `docs/grammar-track-design.md` §9–10;
  `server/src/llm/articleGeneration.ts`, `server/src/llm/articleQuality.ts`.
- **Зависимость:** F-12; отдельное утверждение владельца.
